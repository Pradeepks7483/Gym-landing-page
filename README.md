# Gym Landing Page

## Overview
This is a responsive **Gym Landing Page** built using **HTML and CSS**. The webpage serves as a promotional website for a fitness center, showcasing its services, facilities, and membership options.

## Features
- **Fully Responsive Design**: Works on desktops, tablets, and mobile devices.
- **Modern UI**: Clean and attractive layout with engaging visuals.
- **Call-to-Action Buttons**: Encourages users to sign up or join.
- **Service Highlights**: Displays available gym programs and features.
- **Contact Form**: Allows users to get in touch with the gym.
- **Smooth Navigation**: Easy-to-use and intuitive menu.

## Technologies Used
- **HTML**: For structuring the webpage.
- **CSS**: For styling and responsiveness.

## How to Run the Project
1. Clone the repository:
   ```sh
   https://github.com/Pradeepks7483/Gym-landing-page.git
   ```
2. Navigate to the project folder:
   ```sh
   cd gym landing page
   ```
3. Open `index.html` in your preferred web browser.
